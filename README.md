# AI 室內設計案例影片工作室

GitHub：[Photos_Auto_to_Video-InteriorDesign](https://github.com/yehzonghan-video/Photos_Auto_to_Video-InteriorDesign)

可操作的 Streamlit 網頁：共用密碼入口、照片管理、前端即時標籤／拖曳、Gemini 辨識、多軌時間軸、透明 PNG 圖層、BGM及 FFmpeg H.264 輸出。登入後，沒有 Gemini 金鑰仍能手動製片。時間軸操作、同步與測試請參閱 [第三階段說明](docs/TIMELINE_PNG.md)，音樂參閱 [BGM操作](docs/BGM.md)，AI 設定參閱 [AI 功能說明](docs/AI.md)，輸出限制參閱 [技術可行性](docs/FEASIBILITY.md)。

目前已完成第四階段「裝修前後對比」，並新增0.3秒品牌封面與細黑文字描邊。先選擇裝修介紹或前後對比模板：**上傳照片 → 設定封面 → 配對（對比模板）／選用 AI 標籤 → 加入 PNG → 編輯畫面與時間軸 → 預覽 → 輸出 MP4**。前後配對見 [第四階段說明](docs/COMPARISON.md)，封面操作與測試見 [片頭封面說明](docs/COVER.md)。

## 本機啟動（Windows PowerShell）

需要 Python 3.12（建議與 Cloud 選用同版）、網路安裝套件。Windows 的 FFmpeg 隨 imageio-ffmpeg 套件提供，中文字型使用系統微軟正黑體。也支援自行安裝的 FFmpeg。

```powershell
Set-Location 'D:\自動影片生成'
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

瀏覽器開啟 `http://localhost:8501`。上述命令直接使用虛擬環境內的 Python，不需要另外啟用環境。請先設定共用密碼，登入後即可手動製片；只有 AI 分析需要 Gemini 金鑰。若 `py` 找不到，安裝 Python 3.12 或將建立虛擬環境的命令改成可用的 Python 完整路徑。

本次開發已建立 `.venv` 時，可直接使用 `start.ps1`。關閉終端或按 Ctrl+C 停止服務。

已安裝舊版專案時，先重新執行 `pip install -r requirements.txt`，再重啟 Streamlit，才能載入新增的 Google SDK。

## 共用密碼設定

本機在 `.streamlit/secrets.toml`，Cloud 在 **Settings → Secrets** 新增：

```toml
APP_PASSWORD = "YOUR_PASSWORD_HERE"
```

把範例換成自己的共用密碼；原有 Gemini 設定請保留。未設定或保留範例時，工作室不開放上傳、AI與輸出。也支援伺服器 `APP_PASSWORD` 環境變數，Secrets 優先。

進入頁面輸入密碼，正常編輯不需重複登入；側邊「登出」會清除本工作階段的照片與影片，請先下載成果。修改密碼後需重新驗證。設定與測試詳見 [共用密碼說明](docs/ACCESS.md)。

## Gemini 設定

### 本機 Secrets

在專案內建立 `.streamlit/secrets.toml`，可參考 [.streamlit/secrets.toml.example](.streamlit/secrets.toml.example)：

```toml
GEMINI_API_KEY = "YOUR_API_KEY_HERE"
GEMINI_MODEL = "gemini-3.1-flash-lite"
```

將佔位文字換成自己的金鑰。真實 `secrets.toml` 已被 `.gitignore` 排除，請勿提交至 GitHub；金鑰只由 Python 伺服器使用，不傳給標籤編輯器。修改設定後重啟應用程式。

也可使用伺服器環境變數 `GEMINI_API_KEY` 與 `GEMINI_MODEL`；若同時設定，Secrets 優先。未設定金鑰時，AI 按鈕會停用並說明原因，手動編輯與 MP4 輸出仍可使用。

### 模型與免費方案

預設模型為 **`gemini-3.1-flash-lite`**，選單標示 **「Gemini 3.1 Flash-Lite (建議)」**，已完成真實 API 與瀏覽器五張照片測試。2026-10-12 曾成功測試 3.8 Flash，但後續新金鑰測試遇到連線／逾時；2.5 Flash 在先前新帳號則回傳 404。

介面可選擇下列模型。新工作階段初始選擇建議的 3.1 Flash-Lite，即使既有 Secrets 仍指定 3.8 Flash；使用者自行切換後，一般 rerun 會保留選擇。切換模型不會覆蓋既有標籤，快取依模型分開。

| 模型 | 可用性驗證 |
| --- | --- |
| `gemini-3.1-flash-lite` | 建議／預設；已完成真實 API 與瀏覽器五張排隊／自動套用測試 |
| `gemini-3.8-flash` | 曾完成真實照片 API 測試；後續新金鑰測試逾時 |
| `gemini-3.6-flash` | 官方列有免費層、測試金鑰模型清單有列出；未逐一測試生成 |
| `gemini-3.5-flash-lite` | 官方列有免費層、測試金鑰模型清單有列出；未逐一測試生成 |
| `gemini-2.5-flash` | 部分舊帳號可能可用；先前新帳號實際分析回傳 404 |
| `gemini-2.5-flash-lite` | 官方列有免費層；生成可用性仍依帳號而異 |

分析失敗時**不會自動換模型**。新增型號前需查證免費層並更新 `studio/ai.py` 的允許清單。

查證當日 Google 官方價格頁列有上述模型的免費 Standard 層。請使用未啟用帳務的免費專案金鑰；模型有免費層不代表已啟用帳務的專案一定免費，程式也無法由金鑰查證帳務狀態。實際可用額度請查看 AI Studio。[官方價格](https://ai.google.dev/gemini-api/docs/pricing) · [額度說明](https://ai.google.dev/gemini-api/docs/rate-limits)

AI 分析會把照片副本傳送至 Google。免費方案可能使用輸入及輸出改善產品，並由人工審閱；請勿傳送敏感、機密或個人資訊。介面會在分析前顯示提醒並要求勾選同意。[Google 資料使用政策](https://ai.google.dev/gemini-api/terms)

## BGM操作

1. 加入照片後展開「背景音樂 BGM（預設1秒淡出）」，選音樂檔，按「加入／替換BGM」。請使用有權使用的音樂，單檔最多200 MB，超長音樂自動截取前120秒。原本20 MB是專案自行設定的保護上限，已放寬；200 MB為目前專案上傳上限，與Gemini無關。
2. 在下方編輯器「BGM」調音量、啟用／關閉、是否循環，以及結尾淡出。預設音量50%、循環開啟、淡出1秒；淡出可設0～10秒，0為不淡出。只有BGM採用這個預設，文字與PNG動畫不變。
3. 音樂從影片0秒開始，包含0.3秒封面。短音樂循環至影片結尾；關閉循環則在音樂結尾淡出，影片繼續。設定先留在本地草稿，套用／輸出前才整批同步。
4. 預覽可播放BGM。FFmpeg輸出H.264＋AAC MP4；瀏覽器錄製需同時支援H.264與AAC，無法使用時請用FFmpeg。移除音樂使用上方「移除BGM」，不刪照片與標籤。

資料、限制及驗證詳見 [BGM說明](docs/BGM.md)。

Cloud若顯示`payload() takes from 1 to 8 positional arguments but 10 were given`，是執行中的旧製片模組介面與新版app.py不一致。已加入啟動相容性檢查及必要時重載；更新後仍出現錯誤，先下載成果，再到`Manage app → ⋮ → Reboot app`重新啟動。重啟會清空工作階段照片與草稿，詳見 [版本修復說明](docs/BGM.md#cloud舊模組介面修復)。

## 片頭封面操作

正文上方另外提供標題與LOGO，操作詳見下方「影片正文標題與LOGO」；兩者不套在0.3秒封面上，封面沿用原本配置。

1. 加入照片後，第一張縮圖為「封面0.3秒」，兩套模板共用封面設定；可取消「加入片頭封面」。
2. 在「封面標題」輸入文字，可按 Enter 分行。反白要改色的文字，選「選取字色」，再按「套用選取字色」。其他文字沿用「整段字色」；修改標題會重設局部字色。
3. 從「封面照片」選擇已上傳的照片。預設優先施工後照片；下方完整呈現照片，空白處留黑，不拉伸。
4. 「顯示安全區」在構圖及動畫預覽時顯示標題與照片參考框，不加入MP4。封面標題過長自動縮字，固定留在上方區域。
5. 預覽或輸出前整批套用最新資料。封面占0～0.3秒，其後照片、標籤及PNG依全片時間播放；開關封面時PNG時間跟著平移0.3秒。影片內標籤與封面標題均使用1080p下2px黑描邊。

封面選取時設定自動展開，回到一般照片時收合。片頭依1080×1440（3:4）原稿排版，標題與照片使用原始安全區座標；置頂放入1080×1920（9:16）成片，下方補黑，LOGO與照片不拉伸。詳見 [資料、排版及人工測試](docs/COVER.md)。

## 影片正文標題與LOGO

1. 在編輯器「影片正文 · 標題與LOGO」調整；兩套模板共用，只顯示在0.3秒封面之後。LOGO沿用提供的透明PNG與原稿位置，照片仍完整顯示。
2. 預設勾選「連動封面文字與顏色」：輸入封面標題、設定整段或局部字色時，正文立即跟隨。連動中也能在「正文標題」輸入框用滑鼠反白選字，再選「選取字色」並按「套用選取字色」，顏色會同步封面。取消勾選後會複製目前文字／顏色，可獨立修改；重新勾選即可恢復連動。
3. 正文字級預設100px，可調36～240px；標題區加高，較長標題可分兩行放大。文字過長仍自動縮字，保留2px黑描邊，不輸出框線；安全區以金色虛線提示預設位置。正文預設水平50%、垂直24.5%（文字區中心），可直接拖曳畫布上的正文文字改位置，或調整水平／垂直百分比。选取後用方向鍵微調，Shift＋方向鍵加大步幅；「恢復預設位置（較高）」可重設。位置獨立於封面及LOGO。
4. 下方多軌時間軸新增「正文」軌道，點選標題素材後可拖曳整段改開始時間，拖左右邊界改長度；也可在右側設定開始／結束秒數。預設「正文全程顯示」會跟隨影片長度，手動調時間後切換為自訂，重新勾選即可恢復全程。LOGO仍在正文全程顯示。
5. 修改只保留在JavaScript草稿，套用／輸出時整批同步；不增加影片秒數，標題可跨照片與對比片段。MP4使用相同時間及樣式，封面維持0.3秒。詳見 [設定、測試與限制](docs/BODY_TITLE.md)。

照片的人工／AI裝修標籤預設從該照片第1秒開始；既有標籤各自延後1秒一次，消失時間維持原設定。若剩餘時間不足，限制在片段內至少顯示一影格，只有一影格時直接顯示。施工前／施工後的自動字樣維持與照片切換同步。編輯模式仍顯示全部標籤供拖曳，請用動畫預覽檢查實際出現時間；之後手動改時間不會再被延後。

## 裝修前後對比操作

1. 側邊選「裝修前後對比」，分別加入施工前／後照片。兩區獨立保留選檔；縮圖分類、排序與刪除在編輯器來源庫，替換使用上方功能。
2. 按「依順序自動配對」，或指定前／後照片「新增配對」。數量不等的照片保留未配對；可重用照片，配對可改、刪、拖曳調序。
3. 每組選前後切換（直接／淡化／滑動）、左右分割或滑動揭露。設定停留及轉場；分割線可直接拖曳，揭露使用真正移動遮罩。
4. 查看施工前或施工後，使用現有照片顯示方式與裁切控制獨立調整；再按「顯示對比畫面」。施工前／後為72px純文字，順序播放共用位置，以0.35秒漸隱／漸顯換字；拖曳任一標題一起更新位置。自動文字可編輯，PNG可跨組播放；AI分析來源後可「加入施工後照片標籤」。
5. 預覽並直接輸出，最新配對、文字、裁切及PNG先整批同步。模板切換保留各自的片段與PNG，影片長度只依編輯器現有時間軸推導。

構圖上方的「顯示安全區」可開關參考框，動畫預覽也適用，MP4不顯示。播放時會依封面或正文切換對應安全框。自動施工前／後標題預設放在內框內；使用者仍能自由拖出，照片及其他素材不受限制。

來源合計最多12張，每组1～20秒、最多24組／120秒；重用來源不增加照片張數。其他規則與人工待測步驟見 [完整操作說明](docs/COMPARISON.md)。

## 裝修項目介紹操作

1. 上傳 JPG／JPEG／PNG／WEBP，可一次多張；或載入 5 張自行繪製的測試示意圖。
2. 在照片列點選照片，拖曳縮圖排序。觸控或鍵盤可使用前移／後移按鈕。刪除目前照片與單張替換在照片管理區。
3. 設定每張秒數。預設「完整照片（空白處留黑）」等比例置中保留整張照片，橫式照片上下留黑；需要裁切時，可改選「填滿畫面（裁切照片）」再使用縮放及水平／垂直裁切滑桿。
4. 若要使用 AI，在「AI 分析裝修項目（分析後直接加入標籤）」選擇模型、閱讀資料政策並勾選同意；可一次選全部照片，按「AI 分析並加入標籤」。等待時顯示目前照片、各張狀態、進度與限流倒數；分析成功後直接加入下方編輯器，無須另外採用，既有人工標籤保留。
5. 按「新增標籤」立即顯示完整標籤，直接修改文字及樣式。拖曳畫面上的標籤；拖曳圓形定位點可單獨移動物件位置。這些操作只更新前端草稿，不觸發 Python 同步。
6. 展開樣式與動畫設定：大小、字色、背景、透明度、圓角、連接線、出現／消失時間與進場時長。停留時間為 `消失時間 - 出現時間 - 進場時長`；標籤可錯開出現。
7. 在 PNG 素材庫點選加入箭頭或價格框；自己的 LOGO 先用上方「上傳 PNG 素材」加入素材庫。拖畫布上的 PNG 移動、右下角方點縮放、上方圓點旋轉；右側設定開始／結束、透明度、層級及進出場動畫。
8. 下方多軌時間軸拖素材中央移動、左右邊緣改時間；點秒數刻度或拖紅線跳轉，播放可預覽整部影片。PNG 可跨照片與重疊；文字隨照片排序，照片縮短會截短附屬文字與超過影片結尾的 PNG。編輯模式固定顯示標籤，PNG 依目前時間顯示，操作框不會輸出。
9. 編輯完成後按上方「套用變更」。未套用時使用本機字型即時預覽；套用後校準為與影片輸出相同的標籤素材。切換照片與一般 Streamlit rerun 都會保留照片、文字與 PNG 草稿。
10. 按「瀏覽器 MP4」或下方「輸出 H.264 MP4」都會先確認最新草稿已套用，再開始輸出。瀏覽器錄製需保持頁面前景；FFmpeg 預設 Full HD／30 FPS，也可選 720p 或 360p。完成後播放、下載，清空工作階段可移除照片、上傳 PNG 與影片。

AI 匯入依編輯器當時最新的完整顯示／裁切設定換算座標。物件完全位於裁切外時不匯入；部分可見時修正定位點並標記待確認。匯入後若再次改變裁切，請重新確認標籤與定位點。

不需要的 AI 標籤在編輯器直接刪除或修改。普通 rerun、再次使用相同快取不會重複加入已交付的結果。只有手動勾選「重新分析」或補查失敗照片才再次送出請求；新的分析結果仍保留既有編輯內容。

標籤、排序、構圖與 PNG 設定先保留在 JavaScript 本地狀態，並將純設定草稿存入同分頁的 `sessionStorage`（不含照片／PNG 圖片），元件重建時可恢復。只有「套用變更」及輸出前才整批同步 Python，以事件 ID 與版本號防止重複套用、舊資料覆蓋新編輯。同步失敗保留草稿並顯示錯誤。輸出時只使用已確認的最新設定。

照片上傳至 Streamlit 伺服器並只存在目前工作階段記憶體；FFmpeg 暫存壓縮影片會清除。整頁重新整理、連線斷開或關閉分頁仍可能令伺服器照片工作階段失效，第一版沒有永久專案存檔。瀏覽器不允許 sessionStorage 時，介面提示先套用再離開此頁。未套用草稿時請勿使用先前下載結果代替重新輸出。

一般照片保留原檔，編輯器另外使用較小預覽；大照片或整批負荷超標時自動等比例縮小工作副本並顯示提示，不再因6000萬總畫素、80 MB、單張3200萬畫素或舊15 MB門檻直接拒絕。FFmpeg 使用保留的最高品質工作版本；瀏覽器錄製使用預覽，放大裁切可能較柔。詳細規則、傳輸邊界與測試見 [照片最佳化](docs/PHOTO_UPLOAD.md)。

## 使用限制與錯誤處理

| 項目 | 目前上限或行為 |
| --- | --- |
| 照片 | 每工作階段最多 12 張；工作副本以80 MB／6000萬總畫素為自動最佳化預算 |
| 照片傳輸 | 每檔最高 200 MB；一般照片保留原檔，大照片與整批負荷超標時自動最佳化 |
| 影片與標籤 | 每張 1～20 秒、總長最多 120 秒；每張最多 12 個標籤 |
| PNG 素材／圖層 | 靜態透明 PNG，每張 5 MB／800萬畫素；最多 24 個素材共 40 MB，全片 32 個圖層 |
| AI 排隊 | 可一次選最多 12 張，一張回覆後再送下一張；工作階段最多 20 次 API 呼叫（含補試） |
| AI 程序共用限流 | 同一金鑰每分鐘 5 次、滾動 24 小時 100 次；程序重啟會重置 |
| 重複照片分析 | 依模型、提示版本與照片內容雜湊使用工作階段快取；重新分析只處理所選未完成照片，保留成功結果 |
| AI 失敗 | 區分429／503／504／用戶端逾時，暫時錯誤最多補試兩次，優先Retry-After；明確每日耗盡不補試，仍可手動製片 |
| 未完成補查 | 比對照片 ID、內容、模型及待處理紀錄，按「補查未完成照片」只重送未完成者；空結果仍算成功 |
| 匯入標籤過多 | 自動加入剩餘容量內的項目，顯示未加入數量；既有標籤保留 |

這些 AI 限制是應用程式的安全上限，並非 Google 保證的免費額度。429 表示額度不足或呼叫太頻繁；404 表示模型無法使用；金鑰、權限及 JSON 格式錯誤也會顯示說明。沒有模型自動切換或付費備援。上次佇列可查看每次HTTP狀態、API類型、耗時與診斷代碼；Cloud Logs搜尋`GEMINI_DIAGNOSTIC`，操作與欄位說明見 [Gemini失敗診斷](docs/AI_DIAGNOSTICS.md)。

原先「一次最多 3 張」是程式的保護設定，並非 Google 固定限制。現在使用一般 `generateContent` 逐張排隊，不使用 Google 的 Batch API。Gemini 官方限制依專案、模型與帳號額度而異；等待能處理每分鐘限流，不能解除每日額度或帳號權限限制。

瀏覽器 MP4 依賴瀏覽器的 H.264 支援，且無法保證固定 30 FPS；不支援時按鈕停用，可使用 FFmpeg。免費 Cloud 的 Full HD 渲染效能仍需部署後測試。
