# 影片正文標題與LOGO

正文使用使用者提供的「老屋翻新最低88萬起(7).png」透明品牌圖，儲存為`assets/covers/body-template.png`；「(6).png」僅作排版參考。沒有引入未知授權素材。原稿為3000×5334，顯示與輸出依原比例縮至1080×1920，不拉伸LOGO、不更動照片裁切。標題區寬796、高360像素；預設字級100px，文字區中心水平50%、垂直24.5%，對應左上x=142、y約290px。正文位置現在可獨立拖曳，框線僅提示預設區域，不限制使用者留在該框內，也不燒入成片。

## 操作

- 正文的標題與LOGO各有開關，預設都顯示在封面結束後的所有照片／對比片段；0.3秒封面沿用原本品牌排版，不加入新的正文前景。
- 預設連動封面文字、整段顏色及局部字色。正文標題在連動中為唯讀，仍可用滑鼠反白選字換色；整段字色、局部字色及清除字色會同步修改封面。文字內容請在封面修改，或取消連動。取消連動時複製當下封面內容；後續正文與封面可各自修改。重新勾選後立即改用最新封面內容。
- 正文字級獨立設定，預設100px，範圍36～240px；標題區加高可分兩行放大，過長時自動分行／縮字。最多80字、6行，字色範圍以Unicode字元索引儲存。文字有1080p下2px黑描邊，沒有背景或邊框。舊工作階段的120px／88px預設及未移動的舊預設位置升級一次，其他自訂字級／位置保留。升級後可自由改動，不會在rerun時重設。
- 在右側正文面板修改時，若目前選的是封面，會改看第一個正文片段。正文可直接在畫布拖曳，或調整水平／垂直百分比；選取後方向鍵每次6px，Shift＋方向鍵每次30px。「恢復預設位置（較高）」重設到上移後的位置。LOGO位置維持原配置，原有標籤與PNG仍能任意拖曳並畫在正文前景上方。
- 不會強制挪動既有標籤，標籤與正文重疊時可用原有編輯器調整。

## 正文時間軸

現有時間軸包含「正文」及「LOGO」獨立軌道，各有一段共用素材，與照片標籤及PNG分開。點選素材即開啟右側正文設定；拖整段改開始時間，拖左右邊界改長度。兩者時間互不影響，LOGO位置沿用原配置。這些操作只更新前端草稿，不逐次送Python，也不改照片順序或增加總片長。PNG、照片標籤仍沿用原本軌道。

預設`auto_timing=true`與`logo_auto_timing=true`，從封面後的0.3秒一路顯示到影片結尾，縮短／加長照片會自動跟隨。拖曳或輸入時間會改為自訂全片秒數：標題使用`start/end`，LOGO使用`logo_start/logo_end`。可以跨照片與對比片段；至少一影格，開始包含、結束不包含。自訂區間不進入封面，影片縮短時限制到剩餘正文。重新勾選各自的「全程顯示」即可恢復。開關封面會將兩者的自訂時間一起平移0.3秒。

時間設定與文字、顏色、連動及字級一起留在`cover.body`，沿用sessionStorage、批次同步及輸出前套用，也包含在專案ZIP內。拖曳播放指針時依目前全片秒數分別決定標題與LOGO可見性，構圖與動畫預覽均遵守各自區間。FFmpeg預先準備透明標題與LOGO，依同一時間規則合成，封面影格不套用。舊專案缺少LOGO時間欄位時預設全程顯示；舊頁面同步缺少欄位時保留伺服器既有LOGO時間，避免清掉新設定。

## 資料及同步

LOGO獨立時間也儲存在同一個`cover.body`：`logo_auto_timing`、`logo_start`、`logo_end`；正文資料版本為5，ZIP格式仍為1，舊ZIP可直接匯入。升級版本4時只補LOGO時間，保留既有人工字級、位置與標題時間。

正文設定儲存在`cover.body`，包含`enabled`、`logo_enabled`、`follow_cover`、`title`、`color`、`highlights`、`font_size`、`auto_timing`、`start`、`end`、中心位置`x/y`（0～1）及資料版本。位置與文字光柵分開，拖曳只改座標、重用文字快取；預覽拖曳採實際文字邊界而非整個透明區域，字形保持在影片範圍內，但可移出安全框。Python將同一座標轉成標題區左上位置，沿用原管線輸出。連動時渲染即時讀取封面內容，不維護兩份互相矛盾的文字；取消連動才複製独立內容。

沿用既有草稿、sessionStorage及批次同步機制，不新增Streamlit逐字事件。舊回覆不覆蓋較新的正文草稿，切換照片、模板或元件重建仍保留。伺服器在所有資料驗證成功後才整批提交；舊頁面的事件若缺少正文或時間欄位，沿用伺服器既有設定。輸出仍走原有FFmpeg管線；僅在正文照片／對比畫面與標籤／PNG之間依時間合成透明前景，不另建輸出系統，也不修改AI核心或BGM淡出。瀏覽器同樣在照片上、標籤下繪製。

共用封面文字驗證、局部顏色及光柵邏輯；Python輸出文字光柵在套用後提供瀏覽器校準。編輯中的瀏覽器本地字型可能有少量排版差異，套用後會以校準光柵顯示。LOGO預覽先縮至輸出尺寸，避免瀏覽器解碼原稿1600萬畫素。

啟動版本相容檢查增加共用封面／正文模組，依提供端再消費端的順序重載，避免Cloud保留舊標題函式；一般rerun不重載，照片和草稿不清除。
