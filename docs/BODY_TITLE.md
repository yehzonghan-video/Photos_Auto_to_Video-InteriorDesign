# 影片正文標題與LOGO

正文使用使用者提供的「老屋翻新最低88萬起(7).png」透明品牌圖，儲存為`assets/covers/body-template.png`；「(6).png」僅作排版參考。沒有引入未知授權素材。原稿為3000×5334，顯示與輸出依原比例縮至1080×1920，不拉伸LOGO、不更動照片裁切。依後續放大文字需求，標題維持x=142、y=410、寬796像素，區域高度從160加至360，仍在LOGO下方及正文內安全區。框線只用於安全區提示，不燒入成片。

## 操作

- 正文的標題與LOGO各有開關，預設都顯示在封面結束後的所有照片／對比片段；0.3秒封面沿用原本品牌排版，不加入新的正文前景。
- 預設連動封面文字、整段顏色及局部字色。正文標題在連動中為唯讀，仍可用滑鼠反白選字換色；整段字色、局部字色及清除字色會同步修改封面。文字內容請在封面修改，或取消連動。取消連動時複製當下封面內容；後續正文與封面可各自修改。重新勾選後立即改用最新封面內容。
- 正文字級獨立設定，預設120px，範圍36～240px；標題區加高可分兩行放大，過長時自動分行／縮字。最多80字、6行，字色範圍以Unicode字元索引儲存。文字有1080p下2px黑描邊，沒有背景或邊框。舊工作階段的88px預設升級一次，其他已調整字級保留。
- 在右側正文面板修改時，若目前選的是封面，會改看第一個正文片段。標題與LOGO位置依本次提供的模板固定，沒有新增拖曳功能；原有標籤與PNG仍能任意拖曳並畫在正文前景上方。
- 不會強制挪動既有標籤，標籤與正文重疊時可用原有編輯器調整。

## 正文時間軸

現有時間軸增加「正文」軌道，只有一段共用正文標題素材，與照片標籤及PNG分開。點選素材即開啟右側正文設定；拖整段改開始時間，拖左右邊界改長度。這些操作只更新前端草稿，不逐次送Python，也不改照片順序或增加總片長。PNG、照片標籤仍沿用原本軌道。

預設`auto_timing=true`，從封面後的0.3秒一路顯示到影片結尾，縮短／加長照片會自動跟隨。拖曳或輸入時間會改為自訂全片秒數`start/end`，可以跨照片與對比片段；至少一影格，開始包含、結束不包含。自訂區間不進入封面，影片縮短時限制到剩餘正文。重新勾選「正文全程顯示」即可恢复。開關封面會將自訂正文時間跟著平移0.3秒。LOGO沒有新增時間軌，維持正文全程顯示。

時間設定與文字、顏色、連動及字級一起留在`cover.body`，沿用sessionStorage、批次同步及輸出前套用。拖曳播放指針時依目前全片秒數決定標題可見性，構圖與動畫預覽均遵守此區間。FFmpeg預先準備透明標題，依同一時間區間合成，封面影格不套用。

## 資料及同步

正文設定儲存在`cover.body`，包含`enabled`、`logo_enabled`、`follow_cover`、`title`、`color`、`highlights`、`font_size`、`auto_timing`、`start`、`end`及資料版本。連動時渲染即時讀取封面內容，不維護兩份互相矛盾的文字；取消連動才複製独立內容。

沿用既有草稿、sessionStorage及批次同步機制，不新增Streamlit逐字事件。舊回覆不覆蓋較新的正文草稿，切換照片、模板或元件重建仍保留。伺服器在所有資料驗證成功後才整批提交；舊頁面的事件若缺少正文或時間欄位，沿用伺服器既有設定。輸出仍走原有FFmpeg管線；僅在正文照片／對比畫面與標籤／PNG之間依時間合成透明前景，不另建輸出系統，也不修改AI核心或BGM淡出。瀏覽器同樣在照片上、標籤下繪製。

共用封面文字驗證、局部顏色及光柵邏輯；Python輸出文字光柵在套用後提供瀏覽器校準。編輯中的瀏覽器本地字型可能有少量排版差異，套用後會以校準光柵顯示。LOGO預覽先縮至輸出尺寸，避免瀏覽器解碼原稿1600萬畫素。

啟動版本相容檢查增加共用封面／正文模組，依提供端再消費端的順序重載，避免Cloud保留舊標題函式；一般rerun不重載，照片和草稿不清除。

## 驗證

目前94項Python、53項Node測試通過，包含：

- 局部字色連動、Unicode索引、独立文字、無效欄位拒絕、整批同步回滾及舊事件相容。
- 正文草稿經舊回覆／重建保留，真正editor.js事件連續100次修改不送Python，輸出批次帶最新文字／字色。
- 透明LOGO位置、標題限於參考框、黑描邊、長標題缩字、正文開關不改变封面。
- 兩套模板實際輸出Full HD H.264 MP4，解碼0／9／24影格與預期畫面比較，確認正文從封面後才開始，提示框不輸出。
- 既有AI Mock、標籤、時間軸、PNG、BGM與版本相容回歸；此次沒有真實Gemini API呼叫。
- 正文時間軸整段移動／左右邊界合成300次移動事件不送Python，跨照片、rerun、重建及最新輸出保留時間／240px字級；自動跟隨片長與自訂区間限制。
- 兩套模板實際輸出跨照片／對比片段的自訂標題，解碼15／18／38／45影格，確認開始／結束邊界與LOGO全程保留。

本機瀏覽器實際輸入「老屋翻新最低88萬起」，反白「88」套用金色，確認正文即時跟隨、LOGO與標題位置、取消連動獨立修改及恢復連動。沒有把合成DOM測試當作實體拖曳效能驗證。

時間軸瀏覽器驗證：先設定1～6秒，實際拖整段到2～7秒，拖右邊界延至2～8秒，再拖左邊界到3～8秒；右側設定同步更新。實際預覽4.4秒確認120px兩行標題及LOGO顯示，原照片標籤仍依自身時間播放。Cloud尚未實際驗證。

反白換色修復：原本連動時整個正文標題及換色按鈕被停用，無法選取；現改成唯讀標題搭配可操作字色，連動中也能直接換色。封面／正文共用選取記錄，色盤或按鈕取得焦點造成反白收合時保留同一標題的有效範圍，標題改字後舊範圍失效。同步回覆不重設內容相同的輸入框，避免不必要的游標重設。操作請在上方標題輸入框反白，黑底字色預覽與影片畫布僅供預覽。

此修復通過50項Node與4項正文Python測試，包含失焦後選取保留、連動正文換色同步封面、舊範圍失效、草稿重建及實際兩套模板MP4輸出。本機瀏覽器也確認連動中的正文可反白並套用金色，及實際滑鼠拖曳選取「88」成功；Cloud與其他瀏覽器仍需部署後確認。
