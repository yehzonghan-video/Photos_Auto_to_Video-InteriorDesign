# 時間軸直接編輯與照片操作自動化

本次以 `main` 的 `93990c3` 為基礎，保留第一階段內容雜湊、舊回覆保護、ZIP備份確認與MP4舊版保留。沒有修改Gemini模型／提示詞、登入、影片渲染核心或ZIP格式，也沒有加入新依賴。

## 四項操作

1. **暫停直接編輯**：暫停或seek後維持原時間，能直接選取、拖曳文字與PNG。播放權限、時間、素材選取、動畫姿態與定位輔助分開處理。選取框及命中區使用當下動畫位置／縮放；拖動不會先跳到動畫終點。播放時不接受畫布拖曳。
2. **選檔自動追加**：一般照片與施工前／後兩區均直接追加，逐檔驗證、部分成功。每批完成後清空該角色的上傳控制，下一次可刻意選同檔再加入；不按檔名／照片雜湊永久去重。結果顯示成功／失敗數與各檔原因。
3. **就近替換**：目前照片設定提供「替換照片」；對比可依裁切對象替換施工前／後，來源縮圖也各有替換。開啟原生Streamlit選檔對話框，選檔即替換；取消或解碼／最佳化失敗不改原圖。保留ID、順序、時長、分類、標籤、裁切、PNG、配對引用與動畫。構圖改變仍須檢查定位；AI標籤標記待確認，人工座標保留。
4. **選取設定優先**：文字、PNG、照片、封面及正文選取後，對應區塊以CSS順序置前；不重建欄位，不重設已展開的details。同一素材持續編輯不重複捲動；只在選取對象改變時將設定區回到頂端。窄畫面延用原本上下排列。

未出現的文字仍留在標籤清單，可編輯屬性；按「定位選取文字」才會顯示該文字的靜態定位輔助。這是明確的UI輔助，不改出現／消失時間、不進入專案版本、不輸出。播放或seek會結束輔助。PNG仍依動畫時間顯示，淡入的起始影格可能完全透明。

## 同步與版本

- 播放／暫停／seek、選取、時間軸縮放、設定區排序與定位輔助只改UI狀態，不呼叫`draft.touch`、不送Python、不增加內容revision。
- 真正的文字／PNG／裁切／時間修改仍由現有前端草稿即時處理，沿用套用／輸出前整批同步；沒有恢復每次拖曳rerun。
- 開啟替換只送`replace_photo`輕量請求，包含session、base_revision、nonce及目前來源ID，不把選取當內容修改；伺服器拒絕過期／鎖定請求。
- `photo_intake.batch_id`結合session、角色、uploader epoch及Streamlit file_id（非Streamlit測試物件才以內容雜湊替代）。同一事件收據可重用；下一次選檔有新epoch，允許同圖追加。收據只留最近100批，不寫進ZIP。
- 媒體交易先準備候選資料，成功後交換並呼叫既有`versioning.refresh`；無成功加入或替換失敗不改版本，也不清除MP4／ZIP。
- 媒體回覆沿用`DraftState.merge`保留未套用文字、排序、刪除與對比設定，只換照片名稱、預覽、內容雜湊及需確認標記；舊revision回覆仍被拒絕。換圖後的新內容版本沿用既有狀態判斷，舊MP4標示舊版。
- 清空／匯入後清除媒體收據與替換請求，沿用原本資料保護流程。ZIP格式維持version 1。

## 尚需人工瀏覽器驗收

1. 在桌面瀏覽器播放，於文字／PNG進場途中暫停，直接拖曳、縮放、旋轉；核對當下動畫不跳位，播放續行正常。
2. 將指針停在文字出現之前，確認文字隱藏；從清單修改，再開／關定位輔助，確認時間及版本不變。
3. 快速拖動指針跨照片／封面／對比片段，點選文字、PNG及正文／LOGO軌道，核對預覽、選取與設定。
4. 有未套用標籤、PNG、音樂及對比裁切時替換真實照片；測試比例差異、損壞檔、取消及反覆選同檔，核對引用和人工定位。
5. 手機／觸控驗收：設定區優先、展開狀態、長清單、時間軸及PNG把手；本次沒有宣稱完成實體裝置驗收。
6. 從實際工作流程匯出ZIP、重新匯入並輸出MP4，核對最後文字與圖片；自動化已覆蓋輸出核心與ZIP往返，但不等於Cloud實際操作成功。

## 保留限制與後續

- 不提高12張來源照片、120秒與既有媒體最佳化上限。12張是專案的工作階段資源政策，與Gemini額度無關；對比配對仍可重用照片。
- 若後端已有12張，前端尚未套用的刪除不會在匯入時被擅自提交；須先套用刪除釋放名額，再選新檔。超限檔會明確列入失敗，不靜默略過。
- 草稿仍是工作階段／分頁暫存，不等於ZIP備份。上傳／替換會有必要的Streamlit rerun，但拖曳、seek、編輯與設定優先不送Python。
- 替換保留舊裁切與座標，無AI自動構圖對齊；需要人確認新照片的定位。
- 下一階段可沿用現有內容版本與完整草稿同步，實作ZIP一鍵下載與輸出協調；這次沒有重寫這兩項流程。
