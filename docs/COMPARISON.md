# 第四階段：裝修前後對比

4-1 雙上傳與配對、4-2 現有時間軸整合、4-3 三種對比模式、4-4 MP4 整合均已實作。沿用照片工作階段、前端草稿、文字／PNG 編輯與 FFmpeg 管線；Gemini 核心、登入、資料庫、音樂及品牌片頭片尾沒有新增或更動。

## 操作流程

1. 左側「影片模板」選「裝修前後對比」。出現施工前、施工後兩個批次上傳區；加入一區不會清掉另一區已選的檔案。保留原有大照片自動最佳化。
2. 在編輯器來源庫查看縮圖、分類、前移／後移與刪除。原有裝修介紹照片會顯示為「未分類」，可直接改分類再配對；不需重複上傳。替換使用上方「替換單張照片」，保留原分類、ID 及編輯內容。
3. 「依順序自動配對」按照各組來源順序，追加尚未存在的配對。兩邊數量不同只配對可對應的部分，多餘照片保留並標示未配對。重按不重複加入，也不刪除既有人工配對。
4. 下拉指定前、後照片，按「新增配對」可重複使用照片，甚至建立同樣照片的另一個獨立片段。選取已有片段後可改配對、名稱、模式、時長；縮圖／時間軸拖曳調序，或用前移／後移與刪除片段按鈕。
5. 選對比模式：前後切換（直接切換／淡入淡出／左右滑動）、左右分割、滑動揭露。預設前後切換，以施工前2秒、轉場1秒、施工後2秒播放。
6. 查看施工前／後，再選「填滿畫面」與縮放／水平／垂直裁切；兩側設定獨立。完整照片模式等比例留黑。按「顯示對比畫面」回到對比；左右分割可拖畫布上的分割線。
7. 自動建立施工前、施工後兩個純文字標籤，沒有背景框或定位點。前後切換／滑動揭露共用位置；轉場開始立即隱藏施工前並顯示施工後，拖任一標題會一起更新位置。點標籤清單會跳到對應階段以便編輯。左右分割仍分別顯示兩側文字。可改文字、顏色、大小、動畫和時間；「新增片段標題標籤」可將片段名稱放入畫面。
8. 使用 Gemini 分析來源照片後，在片段按「加入施工後照片標籤」；批次附加、依來源標籤 ID 去重，保留既有標籤。座標依當時獨立裁切／分割換算，裁切外定位點標記待確認。後續再次改裁切／模式或替換照片，請重新確認人工標籤位置。
9. PNG 與原功能相同，可跨不同對比片段、重疊並與文字共用圖層順序。播放預覽會隱藏編輯框並依時間顯示標籤／PNG。
10. 套用或直接輸出；兩個輸出入口均先同步最新整份設定。FFmpeg 提供1080×1920／30 FPS／H.264，亦保留720p、360p。

## 資料結構與同步

所有來源仍是同一組 `Photo`，新增 `role = general / before / after`；原檔或最佳化副本沒有因配對被複製。來源排序即各分類過濾後的排序。

```text
photos                 共用來源照片，含 role、構圖、原有照片標籤
comparisons[]          對比複合片段（可重複引用相同來源 ID）
  id / type            唯一片段 ID / comparison
  before_id / after_id 前後照片 ID
  name / labels        片段名稱／既有格式的文字標籤
  mode                 switch / split / reveal
  duration             片段總長，唯一長度基準
  before_time          施工前停留
  transition_time      轉場／揭露時間
  transition/direction cut/fade/slide、ltr/rtl
  split/show_line      分割比例／分割線
  before_crop          fit、zoom、crop_x、crop_y
  after_crop           獨立的相同裁切欄位
overlays               裝修介紹模板的 PNG
comparison_overlays    對比模板的全片 PNG
```

對比開始時間由排序及前面 `duration` 總和推導，現有時間軸投影提供 `start`，不另存容易失同步的開始秒數。施工後停留由 `duration - before_time - transition_time` 推導；設定施工後停留會更新總長。左右分割使用整段總長，停留及轉場欄位不參與該模式畫面。

片段拉長／縮短時，停留與轉場按比例調整，施工後至少保留一影格。預設兩個標籤時間會隨模式／片段變動更新；人工修改時間後保留人工時間，縮短片段時截短超出部分。文字只能在所屬片段內，PNG 使用該模板的全片秒數，排序時維持絕對秒數；影片變短時截短尾端，規則與第三階段相同。

刪除配對不刪來源。刪除或重新分類來源會移除引用它的配對，其他來源及配對保留。兩個模板分別保留片段標籤與 PNG，切換時不拿另一個模板的時長裁短它們。

所有配對、裁切、模式、分割線、文字、PNG、播放指針與時間軸操作留在 JavaScript 草稿；只有套用／輸出前批次同步。協定版本4包含來源照片、全部配對與兩組 PNG；Python 用輕量 Photo 複本驗證整份資料後才一次提交。nonce／revision 防止重複與舊回覆覆蓋新編輯，sessionStorage 保留純設定，不存照片 bytes。整頁重整／服務重啟仍可能失去伺服器工作階段。

## 三種模式的合成

- 直接切換：轉場為0秒，按施工前停留時間切到施工後。
- 淡入淡出：逐影格混合兩張照片，轉場採平滑插值。
- 左右滑動：整張圖片水平移動；左至右從左側進入，右至左從右側進入。
- 左右分割：每側依自己的區域等比例完整顯示或裁切，沒有拉伸。
- 滑動揭露：逐影格變更施工後的遮罩寬度；Canvas 使用 clip，Python 使用影像 crop。支援兩方向與分割線，不以淡化代替遮罩。

Canvas 與 Python 共用相同姿態公式，底圖合成後再走原有文字／PNG 層級合成、編碼和進度流程。編輯器使用較小照片預覽；FFmpeg 使用保留的最高品質工作照片。放大裁切時預覽可能較柔，位置與時序仍一致。

## 已知限制與人工測試

- 來源照片合計最多12張，配對最多24組，每組1～20秒、全片120秒；可重複引用來源。PNG仍依第三階段上限。
- 照片軌連續播放，左邊界調整與前一片段的共用分界；第一片段從0開始。不提供片段間空隙、音樂或新的片頭片尾。
- 不做AI自動照片對齊。拍攝角度、比例不同需手動裁切；移動分割線後可手動調整標籤，過窄的一側可能放不下較大的文字。
- 來源替換及再次改裁切／模式後，請重新確認先前的定位點。尚無復原／重做、永久專案存檔。
- Cloud效能、多使用者、Safari／Firefox及實體觸控仍需驗證。

人工操作清單：

1. 兩區同時各選一批自己的合法照片，先加入施工前，再加入施工後，確認另一區選檔仍保留；測試刪除、替換及各區排序。
2. 使用3張前、2張後自動配對，確認未配對照片保留；手動建立另一組重用照片，修改配對並刪除片段，確認來源仍在。
3. 三組片段分別使用切換／分割／揭露；切換再測直接、淡化、滑動，揭露測兩方向與遮罩中間影格。
4. 使用橫／直不同尺寸照片，分別調整兩側縮放與裁切，確認沒有拉伸；拖分割線及標籤位置。
5. 拖片段調序與左右邊界，核對後續開始時間及標籤時間；加入跨兩片段 PNG，調層級與文字重疊。
6. 不先套用，切換模板再返回／觸發一般rerun，確認草稿保留；直接輸出、下載，對照最新文字／裁切／遮罩／PNG。
7. 使用自己的Gemini免費金鑰分析施工後照片並匯入標籤，確認定位與既有文字保留；評估真實照片辨識。
