# 0.3秒3:4片頭封面

兩套影片模板共用片頭，預設啟用，可取消「加入片頭封面」。固定0.3秒，在30 FPS成片占前9影格。沿用原有FFmpeg輸出流程；不新增服務、資料庫或永久專案儲存。

## 操作

1. 加入照片後選第一張「封面0.3秒」縮圖，或展開「片頭封面」按「查看與編輯封面」。
2. 輸入標題，Enter分行；最多80個Unicode字元、6行。設定字級36～160px，過長會自動縮至能放入標題安全框的尺寸。
3. 在輸入框反白所需文字，選「選取字色」，按「套用選取字色」。可對不同字組重複操作，後加範圍優先。整段字色仍可修改；清除局部字色還原整段顏色。修改標題內容會重設局部色彩，避免字元索引錯位。
4. 選擇封面照片，完整等比例呈現；預設優先施工後照片，否則第一張照片。刪除來源後改用可用照片。
5. 開關「顯示安全區」查看參考框。構圖及動畫預覽都會顯示，播放至正文時切换正文安全框；MP4不含框線。
6. 按「套用變更」整批保存，或直接輸出，由既有輸出握手同步最新資料。

封面設定在選封面時展開、選一般照片時收合；一般照片仍沿用原有裁切、拖曳、文字及PNG操作。

## 排版與描邊

使用提供的「片頭模板.png」，放在`assets/covers/opening-template.png`，沒有重繪品牌素材。素材與安全區参考圖均為1080×1440；成片維持1080×1920。模板等比例置中，上下各留240px黑邊，LOGO維持比例。

標題與照片沿用3:4安全區参考圖的原始座標，不將垂直位置或尺寸拉長至9:16，以下為3:4原稿內的區域，置中後全片Y座標統一加240px，供開發者在`frontend/cover-layout.json`調整：

| 區域 | X | Y | 寬 | 高 |
| --- | ---: | ---: | ---: | ---: |
| 上方標題 | 246 | 273 | 588 | 292 |
| 下方照片 | 3 | 602 | 1074 | 730 |

封面標題換行、置中並自動縮字；選取照片使用完整顯示，不依一般照片的裁切設定切掉內容。兩個區域固定，這版不提供封面自由拖曳或旋轉。影片內原有素材仍能自由拖出安全框。

封面標題、人工／AI標籤及施工前／後文字均加黑色細描邊，1080p下約2px；較低解析度隨畫面縮放。保留既有標籤背景與動畫設定。LOGO等圖片上的原有文字不另加描邊。

## 時間與同步

- `cover`與照片、標籤、PNG、對比片段分開保存於工作階段及前端草稿。字色範圍使用Unicode字元索引，JS把選取框的UTF-16索引轉換後送出。
- 所有封面編輯先更新JavaScript本地狀態；不新增逐字或逐色Streamlit事件。套用與輸出才透過原有批次事件送至Python，驗證後一次提交。較舊回覆不覆蓋更新的草稿。
- 時間軸開頭顯示不可裁切／調序的封面，原照片／對比片段從0.3秒開始。照片內標籤仍使用原片段相對時間。
- PNG使用全片時間；開關封面時兩套模板的PNG起點一起加／減0.3秒，負時間歸零。新加入PNG仍可放在封面或跨越封面與正文。
- 封面計入120秒全片上限。原有對比／照片片段、重疊PNG、排序及拖曳沿用既有核心。
- Python底層`export_video`呼叫不傳`cover`仍維持原先無封面行为，舊驗證腳本不強制插入片頭。

## 人工待測與限制

1. 部署後選自己的室內照片，輸入多行標題，反白多組字改色；套用、切換照片及一般rerun後確認設定保留。
2. 在正文編輯人工／AI標籤，加入PNG，確認舊操作正常。切換兩套模板、開关片頭及重新排列片段，查看PNG時間是否符合期待。
3. 輸出短片，確認前0.3秒封面、LOGO比例、完整照片、細黑描邊及不含安全框，再測完整Full HD影片。
4. Cloud、其他瀏覽器、實體觸控與長影片負載需於實際環境驗證。本次未驗證瀏覽器錄製的MP4；該功能仍取決於瀏覽器H.264支援，不能保證固定30 FPS，正式輸出建議FFmpeg。
