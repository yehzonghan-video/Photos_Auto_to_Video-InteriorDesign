# 專案儲存與匯入

影片可以另存成一個ZIP專案檔，之後重新登入工作室、匯入檔案，即可繼續編輯與輸出。專案檔放在自己電腦，不需要資料庫或額外服務。

## 儲存

1. 編輯完成後，按編輯器上方「儲存專案檔」。不用先按「套用變更」，系統會批次同步當下的前端草稿。
2. 等待實際素材打包完成，在編輯器下方按「下載專案檔 ZIP（含素材）」。檔名依封面標題產生。
3. 後續再改內容時，重新儲存並下載。下載檔案是儲存當下的快照，不會隨之後的編輯自動改變。

無須先產生MP4也能儲存。沒有修改設定時，儲存專案不會清除已產生的MP4；有更新內容則沿用原有同步行為，清除過期的MP4預覽。

## 開啟

1. 登入後，展開左側「開啟舊專案（ZIP）」，選擇先前下載的ZIP；不用自行解壓縮。
2. 按「匯入並開啟專案」。匯入會取代目前工作區，需要保留原內容時先匯出。
3. 系統完整驗證設定與素材後，開啟新的編輯工作區；失敗時保留原工作區。可繼續調文字、位置、動畫、時間軸及音樂，或直接輸出MP4。

匯入不呼叫Gemini。AI已產生並套用的標籤、說明、類別、信心與人工確認資訊仍然保留。匯入不重設目前登入或本工作階段的AI呼叫用量。

## 保存內容

| 內容 | 保存方式 |
| --- | --- |
| 照片 | 目前影片使用的工作副本、ID、名稱、順序、分類、秒數、完整顯示／裁切、縮放與構圖 |
| 文字標籤 | 人工／AI內容、描述、座標、定位點、線條、字級、字色、背景、透明度、圓角、圖層順序、動畫及時間 |
| 裝修前後對比 | 照片配對、重複引用、播放順序、模式、停留／轉場、分割比例、裁切與片段標籤 |
| PNG | 全部素材庫PNG檔，及兩套模板各自的圖層、位置、旋轉、縮放、透明度、層級與動畫時間 |
| 片頭與正文 | 開關、文字、局部字色、連動、字級、正文位置與顯示區間、LOGO開關及獨立顯示區間／自動跟隨設定 |
| BGM | 影片使用的標準WAV工作副本（最多120秒）、名稱、音量、循環、啟用與淡出 |
| 輸出 | 選用模板、解析度、固定30 FPS；9:16高度由寬度推導 |

如果照片上傳時已自動最佳化，專案保存的是同一個工作副本，不是最佳化前的大原檔；匯入不另外降低工作副本品質。PNG保留Alpha，音樂保存目前輸出使用的解碼內容，不重新轉碼。片頭維持0.3秒、3:4置中；正文與標籤的既有位置及時間會保留，不再次自動延後1秒。

不保存MP4成品、密碼、API金鑰、Secrets、登入狀態、AI待處理佇列或診斷快取，也不保存瀏覽器播放指針與選取狀態。內建品牌模板、字型及渲染程式仍由工作室部署版本提供；ZIP不是其他剪輯軟體的通用專案，跨未來程式版本的像素一致性仍受模板／字型變動影響。

## 格式與驗證

ZIP包含UTF-8的`manifest.json`（格式`interior-video-project`、版本1），以及`media/photos/`、`media/overlays/`、`media/music.wav`。檔案以流水號命名，原始名稱記錄於設定中；各素材以SHA-256校驗完整性。資料版本保留未來遷移空間，未知版本會顯示明確錯誤。

專案壓縮檔及解壓後總量均限制160 MB；維持來源照片12張／80 MB／總6000萬畫素、PNG素材24個／40 MB等現有工作階段限制。一般完整專案的素材總量在此上限內。標題與設定JSON最多4 MB，不允許重複檔案、額外檔案、路徑穿越、加密ZIP或符號連結。匯入只在記憶體讀取，不將ZIP解壓到伺服器目錄，也不讀取外部網址。

所有資料沿用既有`consume_editor_event`交易驗證，確認成功後才替換。新工作區會換`editor_session`並清除過期事件，防止舊瀏覽器草稿覆蓋匯入內容。儲存只送一次完整前端快照，拖曳及逐字編輯不新增Streamlit Rerun。

## 測試與人工確認

自動化涵蓋兩套模板的完整資料／素材往返、字色與動畫、AI標籤保留、損壞與缺漏檔案、無效座標與引用、SHA校驗、大小限制、舊事件失效、登入與AI用量保留、儲存nonce去重、後續編輯不被舊快照覆蓋，以及儲存／匯入的Streamlit工作階段。

實際MP4驗證使用自行產生的照片、透明PNG及WAV，輸出360×640、30 FPS、H.264＋AAC，逐一比對匯入前後的完整解碼影格與音訊雜湊一致。前端操作測試為合成DOM，AppTest匯入來源使用模擬UploadedFile；不代表已通過真實瀏覽器上傳／下載或Cloud部署。

部署後人工測試：

1. 放入自己的照片、兩套模板配對、跨片段PNG及BGM；不按套用，直接儲存、下載ZIP。
2. 清空工作區或重新登入，匯入ZIP，確認照片完整、透明PNG、文字／字色／位置、順序、時間、解析度與音樂設定。
3. 預覽並輸出MP4，確認0.3秒置中片頭、正文與前後切換、PNG透明度與動畫，以及BGM淡出。
4. 修改後再儲存第二份ZIP，確認新修改保留；嘗試損壞ZIP，確認原工作區不被清空。

本次完整回歸：112項Python、60項Node測試通過；其後將專案測試的音檔改為自行產生的440 Hz立體聲可聽測試音，再執行9項專案測試亦通過，包含完整MP4解碼影音一致性。測試素材均自行建立，沒有呼叫真實Gemini API。
