# 第六階段：快速修改標題

以 `main` 的 `237fdc07bdefbace42504e959292cc6ab7e9a809` 為基礎，保留空間導覽與同版本MP4／ZIP輸出。快速模式是現有編輯器的精簡面板，不另建影片、時間軸或輸出系統。

## 操作

1. 登入後選「快速修改標題」，直接在主畫面選擇／拖入ZIP，按「匯入並開啟專案」。取代既有工作區仍經原本未備份保護，匯入失敗保留原資料。
2. 在「影片標題」修改一次文字，封面與正文使用相同內容，也可以清空而只保留照片、LOGO及其他素材。上限80字；繁體中文、英文、數字與標點可用。空標題輸出時，檔名使用「室內設計案例」。
3. 在該輸入框反白要改色的字，再選封面或正文的重點字色並按對應套用。兩邊可不同色；各自設定字級、整段字色、換行及X／Y。排版區只允許新增／移除換行，修改字詞請使用共同輸入框。
4. 選「封面預覽」／「正文預覽」，正文下拉選單切換實際片段。可直接拖曳標題；座標沿用1080×1920畫布的相對中心位置。安全區只提示，不限制拖曳，也不輸出到MP4。
5. 選「原始版本（匯入快照）」比較匯入時的封面或各片段代表影格；切回「修改後版本」可播放、移動指針及繼續編輯。
6. 按原有「輸出 H.264 MP4」；「同時下載 ZIP 專案備份」預設勾選，兩者使用同一固定快照。獨立「下載 ZIP」保留。確認檔案確實存入電腦後，再手動確認該版本備份。
7. 需要修改其他素材時按「進入完整編輯器」，本分頁草稿與排版保留，不必重新上傳ZIP。工作階段重啟仍可能失去素材，請保存ZIP。

## 舊ZIP與共用標題

實際共同來源為 `cover.shared_title.text`，對應穩定元素 `project-cover-title` 與 `project-body-title`。既有封面與正文仍用各自原有的渲染欄位；共同文字按各自換行位置生成顯示文字。封面與正文的字級、顏色、重點字、座標、顯示區間及LOGO時間維持分開。

舊專案若已明確設定正文跟隨封面，可直接讀取；第一次真正修改時才建立新關聯，並將正文當下有效樣式獨立保存。單純進入快速模式不會改寫內容。若舊專案的兩個專用標題各自獨立，需先確認面板列出的封面／正文元素及共同文字來源，才能修改。確認會更新內容版本。

只支援專案既有的專用封面與正文標題，不搜尋取代照片標籤、PNG或其他相同文字。若標題其實做成一般文字標籤，或原專案未啟用封面／正文標題，請進入完整編輯器處理；快速模式不自動新增或啟用它們。

關聯版本1保存於 `cover.shared_title`，含兩個ID、文字、兩側換行位置及封面中心座標；正文位置繼續使用 `cover.body.x/y`。顯示文字或ID不一致、無效座標、過多換行等資料會被交易驗證拒絕。建立關聯後ZIP格式為3；本版讀取1／2／3，未關聯的舊專案仍輸出1／2。舊部署版本不能讀取3，匯入前需更新程式。

重點字沿用既有 `highlights` 的Unicode字元索引與色碼。文字改動後，只有原重點片語在新文字中能唯一對應時保留；缺失或重複而有歧義時移除並提示。單純換行以字元位置重新映射，不做模糊比對。換行最多6行，以字元間斷點保存，不保存空白行。

## 比較、排版與效能

原始版本來自匯入成功當下的深拷貝快照，不隨標題或完整編輯器修改而更新。伺服器使用既有構圖、文字、對比、導覽、PNG及動畫合成函式產生單張540×960比較圖，每個片段首次查看才產生，之後在工作階段快取。若未先匯入ZIP便切入快速模式，基準是首次進入時Python已同步的專案；要取得精確的舊版對照，請先匯入該ZIP。

正文比較優先取真正落在正文標題顯示區間內的代表時間，顯示實際秒數；它是固定比較影格，不能逐幀拖動原始版本。修改後預覽則是原編輯器真實播放時間。新增而原快照沒有的片段無法提供原始影格，會明確報錯。查看原始版本時禁止畫布與標題欄位編輯，輸出仍取修改後草稿。

提示依文字實際像素範圍檢查畫面及內圈安全區；長標題可能由既有渲染器縮字或換行，需目視確認。系統不判斷人物、裝修重點或其他素材是否被遮擋。兩側字級、換行與位置均可獨立調整；沒有新增文字動畫系統，沿用原本顯示時間及合成方式。

輸入、反白改色及拖曳都在JavaScript本地執行，沿用草稿保存與批次同步。預覽切換、看原始影格、播放／暫停、模式切換不更新內容版本；沒有實際差異的欄位操作也不更新。只有文字／樣式／位置／換行或明確關聯的變更才改內容雜湊。舊非同步回應保護、輸出中固定快照、舊MP4保留及手動備份確認沿用既有機制。

## 檔名

三套模板的MP4與ZIP都從輸出快照內的共用標題產生相同主體；尚未關聯時使用封面文字。移除Windows不允許字元、控制字元及問號（包含全形問號），壓縮空白、去除前後空白／句點，主體最多60個Unicode字元。保留字如CON加上前綴；空白或只含特殊符號時用「室內設計案例」。清理不更改影片顯示文字。舊成果保留其原本檔名，不能把新標題套到舊MP4。
